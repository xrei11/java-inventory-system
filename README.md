# Java Inventory Management System

A Java-based inventory management system developed as a final project for an Object-Oriented Programmineg.

## Project Overview

This project is a simple inventory management system designed to organize and manage product information and inventory operations.

## Technologies

* Java
* Object-Oriented Programming (OOP)

## OOP Concepts Used

* **Encapsulation** — organized and protected data within classes.
* **Inheritance** — reused properties and behaviors between related classes.
* **Polymorphism** — allowed objects to behave differently through shared types or methods.
* **Interfaces** — defined common behaviors that classes can implement.

## System Features

* Inventory and product management
* Product information handling
* Object-oriented class structure
* System implementation based on a provided UML design

## Role

**Solo Developer**

Recreated the system by the presented UML Diagram and implemented its structure using Java and OOP principles.
